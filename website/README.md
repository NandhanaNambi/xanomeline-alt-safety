# Xanomeline ALT: public GitHub Pages website

Publish this folder's **contents** to the root of a public GitHub repository. In Settings > Pages select Deploy from a branch, `main`, `/(root)`. The site entry point is `index.html`.

Only aggregate CSVs, figures, and non-identifying documentation are included. Do NOT upload full_adlb.zip, `adlb_full.rds`, participant-level CSVs, the XPT candidate or any individual-level QC/discrepancy extracts.

Current status: educational clinical-analysis portfolio, not a regulatory submission; full ADLB internal checks and transport read-back completed, formal conformance outstanding.
