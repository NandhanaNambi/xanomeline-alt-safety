# ADLB upgrade scope

The original project used an ALT-only Week 2 analysis extract for ANCOVA. An expanded 47-parameter, full-visit SDTM-derived ADLB candidate was subsequently created and subjected to internal checks. The original ANCOVA remains unchanged.

Observed dataset: 59,580 records; 254 participants; 47 laboratory parameters. The 31-column exchange candidate was written as SAS XPT v5 and passed a local read-back comparison reported by the user. Comparisons normalized character blank/NA representations and used documented numeric tolerance. Neither the candidate XPT nor participant-level analysis datasets are published on this static website.

Remaining requirements: approved specification and value-level metadata; baseline/visit rules; independent re-derivation; Define-XML; appropriate version-specific external conformance validation; reviewed disposition of findings. This project does not claim sponsor-approved CDISC conformance.
